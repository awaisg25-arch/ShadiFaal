SHADIFAAL ANDROID PROJECT

Is ZIP mein complete Android Studio project aur GitHub Actions workflow hai.
Original Shadi Faal Nama HTML software app/src/main/assets/index.html mein rakha gaya hai.

APK banane ka asaan tareeqa:
1. ZIP ko extract karein.
2. Is ZIP ke ANDAR ke tamam files/folders GitHub repository ke root mein upload karein (ZIP file ko akeli upload na karein).
3. GitHub repository mein Actions tab kholein.
4. Build ShadiFaal APK workflow select karein aur Run workflow dabayein.
5. Successful run ke Artifacts mein ShadiFaal-APK download karein.
6. Artifact ZIP extract karke app-debug.apk install karein.

Android Studio mein bhi is folder ko directly open karke app build ki ja sakti hai.
